## 2025 Style Recreation

This is an AI created recreation of the 2025 badges with some modifications.
Only the `make-tag` function has to be changed, as no changes to the page layout are needed.

### Modifications

* A person's firstname is now slightly larger
* Sponsor and supporter logos have been added
* Multiple organizations will be added as multiple lines, if present

### Troubleshooting

#### Text is not rendered correctly
This code requires font `NimbusSans`, as the text will overlap otherwise.
Ensure the font is installed, to avoid that error.
On Debian based systems `/usr/share/fonts/opentype/urw-base35/NimbusSans-Regular.otf` is provided by `fonts-urw-base35`.
